# Web pública de la Dra. Gianmary Miozzi

Esta rama contiene únicamente la web pública compilada, preparada para publicarse en la ruta `/mozzi/` de GitHub Pages. Muestra el consultorio en Valencia, Carabobo, y permite solicitar citas por WhatsApp.

El código del panel clínico de demostración, historiales, citas locales y credenciales de ejemplo no se incluye en este repositorio público. Las solicitudes de cita no se confirman automáticamente.

Para activar GitHub Pages, configura **Settings → Pages → Deploy from a branch → main → /(root)**. Publicar el repositorio no activa Pages por sí solo.
